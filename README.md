# RetroGames

Коллекция классических игр и домашних проектов для ретро-платформ.

## Игры

| Файл | Платформа | Размер |
|---|---|---:|
| `alice_durak.bin` | Sega Mega Drive / Genesis (BIN) | 384 KiB |
| `bogatyr_v2.nes` | Nintendo Entertainment System (NES) | 128 KiB |
| `Cipollino.bin` | Sega Mega Drive / Genesis (BIN) | 768 KiB |

> ROM-файлы ещё не загружены в этот репозиторий. Таблица фиксирует состав перед публикацией; ссылки на скачивание появятся после загрузки бинарников.

## Запуск

Используйте эмулятор, совместимый с указанной платформой. Перед распространением убедитесь, что у вас есть права на публикацию соответствующих игровых образов.
